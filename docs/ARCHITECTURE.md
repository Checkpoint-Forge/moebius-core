# Moebius Core 架构说明

返回[维护索引](../AGENTS.md)。
文件级职责与变更路由归 [src/README.md](../src/README.md)，这里只写不会随实现变的设计决策。

## 目标

把一个 three.js 场景渲染成纸墨插画，并让这层画法能独立复用。

三条不可破坏的约束：

- **画法与场景解耦**：内核不 import 演示代码、不读应用状态；动态量由调用方逐帧递入。
- **分档读几何，不读亮度**：排线与描边的判据必须来自法线缓冲，不能来自颜色缓冲的屏幕亮度。
- **尺度按 CSS 像素**：排线间距、墨线宽度、速度线宽都不随设备像素比变化。

## 三遍渲染

| Pass | 目标 | 产出 |
| --- | --- | --- |
| 颜色 | `colorTarget`（HDR `RGBA16F`，无 `EXT_color_buffer_float` 时回退 `RGBA8`+sRGB；可开 MSAA），挂 `DepthTexture` | 场景固有色，线性空间 |
| 法线 | `normalTarget`（默认半分辨率），`scene.overrideMaterial` | rgb = 视空间法线；alpha = `max(0,N·L) × 投影遮罩` |
| 合成 | 默认帧缓冲，全屏 quad | 描边 + 排线 + 纸纹 + 速度线 + ACES + 输出色转换 |

关键取舍：法线缓冲半分辨率。全分辨率要付一整遍场景绘制的代价，而法线只用于求屏幕空间梯度，半分辨率足够；代价是排线档位的边界要用 `fwidth(sunlit)` 柔化，否则一个 facet 会在两档之间跳。

## 为什么 alpha 存受光程度

早期版本用颜色缓冲的亮度分档，结果雾色（线性 luma ≈ 0.41）正好落在阈值中段，把整幅画面压进同一档 —— 表现为"亮面和阴影排线一样密"。
改为在法线 pass 里把 `max(0,N·L) × 阴影遮罩` 满量程写进 alpha：雾、曝光、ACES、LDR 回退都影响不到它。
**任何对这个 alpha 的缩放都会让阈值失去物理含义**（缩一半 = 水平沙面从 0.595 掉到 0.30，直接跌档）。

默认阈值按主光 36.5° 标定：水平沙面 `N·L = sin(36.5°) ≈ 0.595`，高于 `hatchSun3 = 0.50`，所以平沙留平涂；排线只出现在立起来的形和背光坡面上。这是刻意的画面取舍，不是漏排线。

## 两个必须守住的契约

1. **`userData.noNormal`**：Line / Points / Sprite / 透明件不进法线缓冲。合成 pass 会临时隐藏它们。漏打标会让这些几何的背面法线混进缓冲，全屏出现墨纱。
2. **主光只有一份真相**：法线 pass 的入射方向从真实主光的**世界位置**反算。用另一份手写向量会让两遍渲染不是同一个太阳，排线分档与颜色不符。

## 灯光由调用方拥有

内核不管灯光。演示台的 `demo/lights.js` 用方位角 + 仰角算世界位置（`azimuth` 以 -Z 为 0°、顺时针为正），三件事必须记住：

- **角度改的是排线**：仰角决定水平面的 `N·L`。36.5° 时平沙 `N·L≈0.595` 高于 `hatchSun3`，沙面留平涂；降到 9° 就整片开始叠线。强度只改颜色，不改分档。
- **改角度后必须作废法线缓冲**：`N·L` 烤在法线缓冲的 alpha 里，不重画就会"光转了、排线不动"。
- **阴影视锥要盖住可见地面**：视锥外的像素拿不到有效阴影值，会被当成全在阴影里，在地平线附近冒出一圈密排线。视锥越大纹素越粗，靠 `normalBias` 压自遮挡条纹。

## 已知取舍：掠射角的大平面

深度 Sobel 检测的是"屏幕邻域内的深度变化"。一块大平面在掠射角下，相邻像素的深度差本身就很大，于是 `depthWeight` 一旦拉高，远处地面会被整片涂黑 —— 这不是 bug，是深度梯度判据的固有行为。
着色器里另有一层 `groundLike` 坡度补偿：朝上的面在 28–65 单位之后抑制描边。演示台的场景尺度较小，靠**默认 `depthWeight` 保持 40** 规避；把它拉到极端值时会看到地平线发黑，这正是该参数的边界。

## 半分辨率带来的时序问题

法线缓冲按帧复用：相机 / 场景 / 被跟踪子树的矩阵不变时隔帧重画。因此"会动的东西"必须挂在传给管线的 `tracked` 子树下，否则画面在动、法线却是旧的，排线会游动。

## 生命周期

- `prepareScene(root)` 打标后要作废豁免缓存，新增物体后必须重跑。
- `resize()` 同时改两个缓冲、`uResolution`、`uNormalTexel`（法线纹理尺寸不能复用颜色尺寸）与 `uPixelRatio`。
- context 丢失是运行时事件（驱动重置、GPU 进程崩溃）。three 会自动恢复，但渲染目标内容不回来，必须 `invalidate()` + `resize()` 重建。

## 明确不做

- 不做 Bloom / 色差 / 运动模糊：默认抑制会在山坡形成白点的高光，不用重特效掩盖几何。
- 不做逐材质画风角色：场景级 `overrideMaterial` 无法按 mesh 选角色，要做得改渲染器结构。
- 不内置后处理框架（EffectComposer）：只需要一个全屏 quad，自己建比对齐第三方 Pass 语义更省。
