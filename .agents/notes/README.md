# notes/ — 决策与依据记录

只记"为什么这么定"，不记计划、待办、过程流水。

- **决策**：面对岔路口选了 A 不选 B，必须写 `## 替代方案`。
- **依据**：勘察或对照的结论，本身不含选择动作；有下游决策时写 `## 支撑的决策`。

格式：

- 第 3 行必须是状态行：`状态：生效` / `状态：被取代` / `状态：已否决` / `状态：已归档`。
- `被取代` 跟指针行；`已归档` / `已否决` 跟一句话理由。
- 就地标记，不建 `archived/`。
- 不写本机路径、账号、环境细节。

写作约束见 [../../AGENTS.md](../../AGENTS.md)。
